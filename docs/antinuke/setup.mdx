# Introduction

<Callout type="info">
  Replace ``[prefix]`` with your own prefix. Type ``@evict#6621 prefix`` to get your server prefixes, however, ``;`` is default.
</Callout>

AntiNuke aims to stop users from taking too many destructive actions against your server. Stop users from banning or kicking all your members by setting up a custom
threshold tailered to your server.

## Enable AntiNuke Ban

Prevent users from massbanning a bunch of people from your server.

To enable antinuke ban, run the following command:

```python
[prefix]antinuke ban enable
```

<Frame>
  <img src="/img/antinuke/examples/ban/antinuke-ban-default.png" alt="AntiNuke ban Default" width="600" />
</Frame>

To set a custom threshold for how many bans trigger antinuke, pass the `--threshold` flag:

```python
[prefix]antinuke ban enable --threshold 3 --duration 1h --punishment strip
```

&nbsp;

| Flag | Description |
|---|---|
| `--threshold` | Number of bans before antinuke triggers |
| `--duration` | Time window to count bans within |
| `--punishment` | Action taken against the attacker: `ban`, `kick`, or `strip` |


<Frame>
  <img src="/img/antinuke/examples/ban/antinuke-ban-1.png" alt="AntiNuke Ban Example" width="600" />
</Frame>

## Disable AntiNuke Ban

Disable the antinuke protection module.

To disable antinuke ban, run the following command:

```python
[prefix]antinuke ban disable
```
